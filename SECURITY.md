# Security policy

## Supported version

Only the latest deployed `v1.x` release receives security and privacy fixes.

## Reporting

Do not publish tokens, personal data, private repository names, or exploit details in a public issue.

Use the repository Security tab's private vulnerability-reporting flow when it is available. If the private flow is unavailable, open a minimal public issue that asks the maintainer to establish a private channel, without including sensitive details.

## Site boundary

This is a static site with no account system, form handler, analytics, cookies, database, or server-side application code. Reports about third-party projects linked from the portfolio should be filed in the corresponding project repository.
