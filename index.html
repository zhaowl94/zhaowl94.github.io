03 / DATA PIPELINE

数据如何更新

GitHub Pages 是静态站，因此数据计算与页面读取被明确拆开。

  1. 01

    定时抓取

    GitHub Actions 从公开行情与基金数据源采集最新数据。

  2. 02

    离线计算

    生成溢价、估值、趋势、回测与相似度所需的版本化快照。

  3. 03

    质量校验

    静态检查、跨浏览器测试和可访问性检查通过后才部署。

  4. 04

    页面刷新

    你点击刷新时，浏览器绕过缓存读取最新已发布快照。

这也意味着：按钮不会在你的浏览器中运行 Python，更不会要求任何 GitHub 权限；若上游源暂时失败，页面会继续展示最近一次有效快照。
